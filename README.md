# スプレッドシート統合ツール

外部キーで各シートに分割されているデータを一つのシートに統合するGoogle Apps Scriptツールです。

## 機能

- 複数のシートから外部キーに基づいてデータを統合
- 設定シートで統合するデータを柔軟に指定
- 自動的にカラム名にシート名プレフィックスを付与
- JSON形式でのデータ出力に対応

## 使い方

### 1. デプロイ

```bash
npm install
npm run deploy
```

### 2. 設定シートの作成

スプレッドシートを開くと、メニューバーに「シート統合ツール」メニューが表示されます。

1. 「シート統合ツール」→「設定テンプレート作成」を選択
2. 「sm.settings」シートが作成されます

### 3. 設定シートの編集

#### 設定シートの構造

| 項目 | 内容 |
|------|------|
| **A1セル** | "外部カラム" (固定) |
| **B1セル** | 外部キーとして使用するカラム名 (例: "id") |
| **A2セル** | "探索範囲(行)" (固定) |
| **B2セル** | 外部キーカラムを探索する範囲(行数)、デフォルト: 10 |
| | |
| **A3セル** | "シート名" (ヘッダー) |
| **B3セル** | "カラム名" (ヘッダー) |
| **A4セル以降** | 統合したいシート名(同じシート名を複数行に記入可能) |
| **B4セル以降** | 各シートから取得したいカラム名(1行に1カラム) |

#### 設定例

```
外部カラム           | id
探索範囲(行)       | 10
                   |
シート名            | カラム名
ユーザー            | name
ユーザー            | email
ユーザー            | department
注文                | order_date
注文                | amount
注文                | status
配送                | shipping_address
配送                | delivery_date
```

この設定により、`id`をキーとして以下のように統合されます:

- 各シートの先頭10行以内で`id`カラムを探索
- `ユーザー`シートから: `name`, `email`, `department`
- `注文`シートから: `order_date`, `amount`, `status`
- `配送`シートから: `shipping_address`, `delivery_date`

### 4. データ統合の実行

1. 「シート統合ツール」→「データ統合実行」を選択
2. `sm.integrated_data`シートが作成され、統合結果が出力されます

### 5. JSON形式での出力（オプション）

1. 「シート統合ツール」→「JSON出力」を選択
2. 統合データがJSON形式でダイアログに表示されます

### 6. 選択した主キーのみのJSON出力（オプション）

特定の主キーのデータのみをJSON形式で出力したい場合:

1. 任意のシート（例: `sm.integrated_data`）で、出力したい主キーの値が含まれるセルを選択します
   - 例: idカラムから「1」「3」「5」を選択（複数セル選択可能）
2. 「シート統合ツール」→「選択主キーのJSON出力」を選択
3. 選択した主キーに対応するデータのみがJSON形式でダイアログに表示されます

**注意事項:**

- 選択したセルの値が主キーとして使用されます
- 空白セルは無視されます
- 存在しない主キーを選択しても、その主キーのデータは出力されません

### 出力形式

出力シートは以下の形式になります:

**1行目**: シート名行

| id | ユーザー | ユーザー | ユーザー | 注文 | 注文 | 注文 | 配送 | 配送 |

**2行目**: カラム名行

| id | name | email | department | order_date | amount | status | shipping_address | delivery_date |

**3行目以降**: データ行

| 1  | 山田太郎 | yamada@... | 営業部 | 2025-01-15 | 10000 | 完了 | 東京都... | 2025-01-20 |
| 2  | 佐藤花子 | sato@...   | 開発部 | 2025-01-16 | 25000 | 処理中 | 大阪府... | 2025-01-22 |

### JSON出力形式

JSON形式で出力すると、ダイアログに以下のような構造で表示されます:

```json
[
  {
    "id": "1",
    "ユーザー": {
      "name": "山田太郎",
      "email": "yamada@...",
      "department": "営業部"
    },
    "注文": {
      "order_date": "2025-01-15",
      "amount": 10000,
      "status": "完了"
    },
    "配送": {
      "shipping_address": "東京都...",
      "delivery_date": "2025-01-20"
    }
  },
  {
    "id": "2",
    "ユーザー": {
      "name": "佐藤花子",
      "email": "sato@...",
      "department": "開発部"
    },
    "注文": {
      "order_date": "2025-01-16",
      "amount": 25000,
      "status": "処理中"
    },
    "配送": {
      "shipping_address": "大阪府...",
      "delivery_date": "2025-01-22"
    }
  }
]
```

**注意:** データサイズが50,000文字を超える場合は、ダイアログに表示できないため警告が表示されます。その場合はデータ量を減らすか、別の方法での出力を検討してください。

## データ要件

### 各シートの形式

- ヘッダー行: 外部キーカラム名を含む行(探索範囲内に必須)
- データ行: ヘッダー行の次の行から
- 探索範囲: 各シートの先頭から指定した行数までを探索
- データが途中の行から始まる場合も対応可能

### データ統合のルール

- 外部キーが一致する行を横に結合
- 該当データがない場合は空欄
- 外部キーが重複している場合は、最後の行のデータが使用されます

## トラブルシューティング

### エラー: 設定シートが見つかりません

→ 「設定テンプレート作成」を実行してください

### エラー: 外部キーカラム名が設定されていません

→ 設定シートのB1セルに外部キーカラム名を入力してください

### エラー: データソースが設定されていません

→ 設定シートの4行目以降にシート名とカラム名を入力してください(1行に1カラム)

### 警告: シート "XXX" の探索範囲内に外部キーカラム "YYY" が見つかりません

→ 探索範囲を増やすか、シート内の外部キーカラム名を確認してください

### 警告: シート "XXX" が見つかりません

→ 設定シートで指定したシート名が存在するか確認してください

### 警告: カラム "XXX" が見つかりません

→ 指定したカラム名がシートに存在するか確認してください
